# Business Booking Bot

A Telegram bot for booking beauty-salon appointments.

## Features
- Book a service by choosing a date and time
- View your bookings
- Cancel a booking
- Admin notification on every new booking

## Stack
Python · python-telegram-bot · ConversationHandler

## Run
1. Create a `.env` file with `BOT_TOKEN` and `ADMIN_ID`
2. `pip install python-telegram-bot python-dotenv`
3. `python bot.py`
